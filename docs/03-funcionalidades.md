# Objetivos del usuario y funcionalidades — Lash Beauty

> Guía: [Objetivos del usuario y funcionalidades](../evaluacion/guias/fase-1-requerimientos/03-funcionalidades.md)

## Objetivos de la proto-persona en el sitio

<!-- Qué quiere lograr tu proto-persona cuando entra a tu sitio.
Revisa sus necesidades y frustraciones: ahí suelen estar los objetivos. -->

1. Encontrar pestañas de buena calidad y comparar opciones fácilmente.
2. Aprender a aplicar y cuidar sus pestañas con consejos confiables.
3. Comprar de forma rápida y segura, y enterarse de novedades y promociones.


## Funcionalidades

<!-- Incluye las 7 funcionalidades base y al menos 5 propias.
Redáctalas como "El usuario debe poder...".
Prioridad: Imprescindible / Deseable / Futuro. -->

| Proto-persona | Objetivo | Funcionalidad | Tipo | Prioridad |
|---|---|---|---|---|
| Sofía | Enterarse de novedades y descuentos | El usuario debe poder dejar sus datos para recibir novedades, promociones y descuentos de bienvenida | Base (landing) | Deseable |
| Sofía | Encontrar consejos según lo que le interesa | El usuario debe poder navegar los artículos por categoría (cuidados, tutoriales, tendencias) | Base (blog) | Deseable |
| Sofía | Compartir su opinión y resolver dudas con otras personas | El usuario debe poder comentar un artículo | Base (blog) | Futuro |
| Sofía | Recomendar contenido útil a sus amigas | El usuario debe poder compartir un artículo en redes sociales (Instagram, WhatsApp) | Base (blog) | Deseable |
| Sofía | Encontrar rápidamente el producto que busca | El usuario debe poder buscar productos por nombre o tipo de pestaña | Base (tienda) | Imprescindible |
| Sofía | Comparar opciones según su gusto y presupuesto | El usuario debe poder filtrar productos por estilo, largo o precio | Base (tienda) | Imprescindible |
| Sofía | Comprar de forma rápida y segura | El usuario debe poder ver el detalle de un producto, elegir el modelo y agregarlo al carrito | Base (tienda) | Imprescindible |
| Sofía | Saber cómo se ven realmente las pestañas antes de comprar | El usuario debe poder ver fotos y videos reales de cada modelo de pestañas puestas | Propia | Imprescindible |
| Sofía | Aprender a aplicar y cuidar sus pestañas en casa | El usuario debe poder ver tutoriales paso a paso de cómo aplicar y cuidar sus pestañas | Propia | Deseable |
| Sofía | Elegir el modelo ideal para su tipo de ojo | El usuario debe poder responder un test rápido para recibir una recomendación de pestañas según su tipo de ojo y ocasión | Propia | Deseable |
| Sofía | Resolver dudas antes de decidir su compra | El usuario debe poder contactar al emprendimiento por WhatsApp para resolver dudas antes de comprar | Propia | Imprescindible |
| Sofía | Confiar en la calidad del producto gracias a otras clientas | El usuario debe poder leer reseñas y calificaciones de otras clientas | Propia | Futuro |
