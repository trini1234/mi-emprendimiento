## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Crear la estructura y el diseño visual del sitio web de pestañas |
| Versionado | Git y GitHub | Guardar el historial de cambios del proyecto y trabajar de forma ordenada |
| Publicación | GitHub Pages | Publicar el sitio en internet para que Sofía y otras clientas puedan verlo |
| Diseño | Whimsical | Hacer el mapa del sitio y los wireframes (bocetos) de cada página |
| Diseño | Google Stitch | Generar y probar diseños visuales de las pantallas del sitio |
| IA | Claude | Ayudarme a redactar textos, completar documentos y resolver dudas del código |
| Editor | Visual Studio Code | Escribir y editar el código HTML y CSS del proyecto |

| Funcionalidad | Estado en esta versión |

| Ver fotos y videos de los modelos de pestañas | Funcional |

| Contactar por WhatsApp (botón con enlace directo) | Funcional |
| Buscar y filtrar productos | Prototipo visual |
| Agregar productos al carrito | Prototipo visual |
| Dejar datos para recibir novedades | Prototipo visual |

## Integraciones para una versión real

- Pasarela de pago (Webpay, Mercado Pago o Flow) para que Sofía pueda pagar de forma segura
- Base de datos de productos y stock para el buscador, los filtros y el carrito
- Servicio de correo (Mailchimp o similar) para enviar novedades y descuentos a quienes dejen sus datos
- Sistema de comentarios y reseñas con moderación
- Servicio de envíos para calcular costos y hacer seguimiento de los pedidos

## Restricciones

- **Plazo:** Entrega del proyecto dentro del plazo definido por el curso, por lo que se prioriza lo imprescindible
- **Marca:** Estilo femenino, delicado y elegante, con colores y tipografías coherentes con la identidad del emprendimiento
- **Dispositivos:** Diseño responsive, pensado primero para celular (donde Sofía navega más) y también adaptado a computador
